📦 Lector de Códigos de Barras 10A

Matemática + Tecnología + Ingeniería + Arte + Ciencia

📷 1. Escanear

Permite el acceso a la cámara y apunta al código de barras.

Formatos especialmente útiles para este proyecto: EAN-13, EAN-8, UPC-A y CODE-128.

🔎 2. Buscar por número

Si la cámara no funciona, escribe el número que aparece debajo del código.

🧮 3. Comprobación matemática EAN-13

Para un EAN-13, la aplicación puede verificar el dígito de control del código.

Escanea o escribe un código EAN-13 para mostrar el procedimiento.

🧑‍🔬 4. Reto STEAM

  1. Diseña un producto ficticio.
  2. Asigna los 12 primeros dígitos.
  3. Calcula el dígito de control.
  4. Genera e imprime el código de barras.
  5. Escanéalo con esta aplicación.
  6. Modifica una condición: tamaño, distancia o impresión.
  7. Vuelve a probar y registra el resultado.
Proyecto educativo STEAM — Los códigos mostrados son identificadores ficticios para uso escolar.
